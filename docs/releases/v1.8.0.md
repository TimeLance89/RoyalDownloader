# RoyalDownloader v1.8.0

Stable v1.8.0 brings the tested Overnight changes to the official Stable
release: easier mobile navigation, optional privacy egress, more responsive
episode checks, and fixes for series identity, subscription notifications and
AniWorld search.

## Highlights

- **AniWorld joins global anime search.** Results open the correct provider's
  detail view. Catalogue titles and aliases provide a fallback when the AJAX
  search fails, with pagination and cached search during provider outages.
- **Mobile navigation and layouts are improved.** Touch targets, safe-area
  spacing, catalogues and dialogs adapt more consistently to mobile screens.
  The language-profile dialog is translated into every supported UI language.
- **Episode checks show live progress.** Enabled sources are checked with
  bounded shared work; verified episodes appear progressively without rebuilding
  the entire selection. Late successes are retained for retries.
- **Complete season selections can wait for sources.** All requested episodes
  enter the download plan while checks are pending and retain their requested
  language contract.
- **Confirmed fallback episodes remain selectable.** Published provider tracks
  and verified sources take precedence over conflicting TMDB dates, while
  explicitly upcoming provider episodes remain locked.
- **Same-name series versions keep the correct identity.** Release-year matching
  separates originals and remakes in metadata caches, subscription matching and
  merged provider snapshots.
- **Subscription download notifications are restored.** Completed episodes keep
  their unread inbox receipt and bell badge even when concurrent checks have
  already removed them from pending.
- **Optional privacy egress centralizes outbound routing.** Providers, downloads,
  browser sessions and external integrations can use a validating proxy.
  Privacy mode fails closed; direct routing remains the default. Explicit local
  integration routing is preserved. See [Privacy Egress](../EGRESS.md).

## Compatibility

Existing accounts, household profiles, sessions, queues, subscriptions, provider
preferences, Jellyfin mappings, media paths, Storage Autopilot policies and
update-channel settings remain compatible. The release preserves the existing
HTTP, `/api/v1`, WebSocket and persistent-data contracts.

## Upgrade

Back up at least `.env`, `data/` and `runtime/`, then update through the Stable
updater or a checkout pinned to `v1.8.0`. See the [release guide](../RELEASE.md)
for installation, verification and rollback commands.

After startup, verify the displayed version is v1.8.0, check your existing
subscriptions and queue, and confirm Jellyfin mappings and media paths. Privacy
egress is optional and requires a configured proxy; upgrading does not enable it
automatically.

## Rollback

Use the normal Stable rollback flow to activate the previous complete runtime.
Keep your `data/` and `runtime/` backup available. See the
[release guide](../RELEASE.md#rollback) for source-tag and runtime rollback.

## Verification

The official release workflow runs the full Quality gate before creating the
annotated tag and GitHub Release. It includes browser regressions, Python tests
and coverage, security/dependency checks, container startup, and upgrade,
restart, rollback and backup-recovery tests. Coverage and module-size thresholds
remain unchanged.

## Known limitations

Third-party provider availability remains external to RoyalDownloader. Cached
AniWorld search needs a previously loaded catalogue when both upstream search
and catalogue endpoints are unavailable; details and streams still require the
source. Deferred episodes wait until a source can prove the requested language.
Privacy egress does not provide an anonymity guarantee.
