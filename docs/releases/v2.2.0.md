# RoyalDownloader v2.2.0

## Highlights

- Browse searchable Film Worlds built around studios and franchises, with
  Jellyfin-aware collection completion.
- Open personal saved films and series from the Merkliste carousel on Home.
  Catalog results also benefit from daily featured rotation and fresher series feeds.
- Install Royal through the native Windows/NAS wizard with verified source
  archives, a private Windows runtime and SSH host-key confirmation for NAS setup.
- Keep active series downloads through provider changes and incomplete language
  probes. Subscription checks retain the original queue identity for the same
  series, season and episode and avoid duplicate fallback entries.
- Verify completed German-selected series with a local Whisper runtime.
  Two initial audio samples can be followed by a third and fourth when needed.
  Two agreeing detections at 90% or higher confirm a spoken-language verdict.
- Attempt Huhu series sources explicitly labelled German and persistently
  exclude a Huhu episode when its audio is confirmed to be another language.
- Show language waits neutrally in the subscription inbox and both episode
  views. Inspect transfer progress, source selection, audio evidence and
  results on the authenticated `/check/` page.
- Improve duplicate Jellyfin-series playback, episode descriptions, direct
  HTTP resume, source routing and stream-proven audio metadata.

## Compatibility

Existing accounts, settings, queues, subscriptions, media directories and
versioned runtime paths remain supported. Application capabilities report
`application_version: 2.2.0`.

The Windows/NAS installer includes the source revision identified by this
release and a SHA-256 checksum. The Fire TV app uses its own version numbering.

## Upgrade

Back up your configuration and persistent application data. Follow the
[release operations guide](../RELEASE.md#backup-before-an-update) before replacing
a running installation.

For a version-pinned Docker source installation:

```bash
docker compose down
git fetch --tags origin
git status --short
git switch --detach v2.2.0
docker compose config --quiet
APP_COMMIT_SHA="$(git rev-parse HEAD)" docker compose up -d --build
curl --fail http://127.0.0.1:8765/api/v1/health
curl --fail http://127.0.0.1:8765/api/v1/capabilities
```

Review local source changes before switching versions. Verify version 2.2.0,
your media mounts, queue recovery and subscription rules after startup.
The normal Stable updater follows the existing staging and rollback process.

## Known limitations

- Spoken-language verification requires a separately installed `whisper-cli`
  executable and `ggml-tiny.bin` model under persistent
  `data/audio-language/` or `/opt/royal-audio-language/`.
  The source package and installer do not bundle this runtime.
- Unclear or unavailable audio checks remain visible in Download-Check and
  follow the provider-selected download. Confirmed foreign-language results
  reject the file. Provider labels alone can be inaccurate.
- Third-party source availability and Jellyfin playback depend on the provider,
  server configuration, supported codecs and network conditions.
- The native installer is unsigned. Verify the published SHA-256 checksum
  and follow the [native installer guide](../EASY_INSTALL_NATIVE.md).

## Rollback

Use the existing runtime rollback or restore the v2.1.0 source revision with
your compatible backup. See [rollback operations](../RELEASE.md#rollback).
